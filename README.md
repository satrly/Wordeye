# WordEye

Приложение для изучения иностранных слов, встреченных в текстах, на скриншотах и фотографиях. Пользователь выбирает слово, узнаёт его перевод, сохраняет вместе с исходным предложением и повторяет с помощью флеш-карточек.

## Как добавить слово

### Выделенный текст на ПК

Пользователь выделяет слово в тексте и вызывает WordEye сочетанием клавиш. Приложение показывает перевод и предлагает сохранить слово в словарь и колоду. Этот сценарий подходит для сайтов и других источников, где текст можно выделить и скопировать.

### Скриншот на ПК

Пользователь вызывает создание скриншота сочетанием клавиш, выбирает на изображении нужное слово и смотрит его перевод. Затем он может сохранить слово. Этот сценарий подходит для текста, который нельзя скопировать напрямую, например в игре или в субтитрах видео.

### Фото или скриншот на телефоне

Пользователь открывает WordEye, загружает фотографию или скриншот из галереи и выбирает слово на изображении. Приложение показывает перевод и предлагает сохранить слово.

Слово добавляется в словарь и колоду только после подтверждения пользователя.

## Словарь и колоды

В словаре пользователь просматривает сохранённые слова, их переводы и исходные предложения, если они доступны. Слова распределяются по колодам.

Для каждой колоды пользователь может отдельно настроить число новых карточек в день, лимит повторений и желаемую продолжительность занятия.

## Флеш-карточки

На лицевой стороне карточки показаны перевод слова на русском языке и предложение на изучаемом языке. Изучаемое слово в предложении заменено пропуском. Для карточки используется предложение, в котором пользователь первоначально встретил и выделил слово.

После нажатия **«Показать ответ»** приложение показывает слово. Пользователь оценивает, насколько хорошо вспомнил его: **«Плохо»**, **«Нормально»**, **«Хорошо»** или **«Отлично»**.

WordEye использует интервальное повторение: дата следующего показа карточки зависит от оценки ответа. При более уверенном ответе интервал до следующего повторения увеличивается.

## Синхронизация

Пользователь может войти в одну учётную запись на нескольких устройствах. Между ними синхронизируются сохранённые слова, колоды, настройки и прогресс повторений.
